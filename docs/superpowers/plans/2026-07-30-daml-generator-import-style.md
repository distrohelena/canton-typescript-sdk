# DAML Generator Import Style Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in plain-`ts-node` import mode while preserving ESM `.js` imports as the generator default.

**Architecture:** A single `DamlModuleImportStyle` value travels from direct generator options or strict CLI parsing into `ProjectEmitter` and a shared relative-specifier policy used by all emitters. ESM keeps `.js`; ts-node emits extensionless relative paths. Integration tests execute source generated by ts-node mode through a CommonJS `ts-node` fixture.

**Tech Stack:** TypeScript, ts-node, Vitest, Node CommonJS and NodeNext.
